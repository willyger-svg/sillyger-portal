Copy Command & Run Kwenye Termux ⚡

Kwa usalama wa Android, bonyeza kitufe kimoja cha Copy & Fungua Termux hapa chini. Ukishaingia ndani ya Termux, bonyeza screen muda mrefu → Paste → Enter. Ita-install git, nodejs, clang/gcc (kwa C Programming), python, gh, na Gemini CLI moja kwa moja!

AI Coding Agents za Bure (Toolkit Yako) 🤖

Mbali na Google Antigravity, hizi ni zana nyingine za bure unazoweza kuweka kwenye Termux ukaanza kujenga websites na apps leo:

Google • Bure

Gemini CLI

AI agent rasmi ya Google kwenye terminal. Ingia na Gmail yako upate free tier kubwa.

npm i -g @google/gemini-cli
Open Source • Bure

Qwen Code

Coding agent ya kasi yenye free tier nzuri sana kwa kujenga miradi ya web na C.

npm i -g @qwen-code/qwen-code
Multi-Model • Bure

OpenCode

Inaunganisha models nyingi za bure (Gemini, OpenRouter, Groq, GitHub Copilot).

npm i -g opencode-ai
C Programming • Offline

GCC / Clang (Termux)

Compile na run code zako za C (Hello World, scanf, n.k.) moja kwa moja kwenye simu!

clang hello.c -o hello && ./hello

❓ Maswali ya Haraka & Msaada

Kwa nini Termux haiji-run command yenyewe moja kwa moja?

Kwa usalama wa Android, browser haiwezi ku-execute command moja kwa moja kwenye Termux. Ndio maana kitufe cha Copy & Fungua Termux kinakucopy-ia command tayari — wewe unagusa tu screen muda mrefu ndani ya Termux kisha Paste → Enter.

Termux ikiniuliza [Y/n] au [default=N] wakati wa ku-install nifanyeje?

Bonyeza tu Enter (au andika Y kisha Enter) ili kuruhusu updates zimalizike.

Sina laptop kabisa — je kweli nitaweza kutengeneza website au app?

Ndiyo 100%! Kwenye Termux una Linux kamili yenye Node.js, Python, Git, C compiler, na AI Agents zinazoweza kuandika code, ku-test server kwenye simu yako, na kupandisha mradi wako live kwenye GitHub Pages!
